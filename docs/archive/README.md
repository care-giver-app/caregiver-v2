# Archive

Historical design records from F1, B1, B3a, and C1, dated `YYYY-MM-DD-*`. They record decisions that
were made at the time and are **never updated** — a dated record of a past decision cannot go stale
the way a description of intended behavior can.

They are not specifications. `docs/PRD.md` is the only document that describes the product. Read
these for the reasoning behind how something came to be built, never for what it should be.
